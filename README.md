# React Utility Dashboard

A simple utility dashboard built with React and Vite.

## Features

- Counter with Increment, Decrement, and Reset
- Custom counter step value
- Prevents counter from going below 0
- Random number generator
- Custom Min and Max range
- Input validation
- Responsive and clean UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
